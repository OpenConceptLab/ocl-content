# 08. Folder Reference

Every file and folder in `LOINC-OCL-ETL/`, what it is for, and whether it is tracked in
git. "Ignored" means matched by a `.gitignore` rule (either this folder's own
`.gitignore` or the repo root's).

```
LOINC-OCL-ETL/
├── README.md                        quick-start: setup, run, QA sample, known limitations
├── docs/                            this documentation
├── loinc_to_ocl_transformer.ipynb   the pipeline
├── File Splitter.ipynb              helper: split outputs for upload
├── id-check.ipynb                   helper: list ids from an OCL export
├── pyproject.toml, uv.lock          Python dependencies (uv)
├── .python-version                  3.13
├── .gitignore
├── Source-Import-files/             hand-maintained OCL Source definition
│   └── Archive/                     older Source definitions
├── QA-Load-files/                   committed QA sample (Phase 7)
├── Input/                           ignored: CSVs copied from the release (Phase 0)
│   ├── LinguisticVariants/
│   └── MRCONSO.RRF                  ignored: UMLS, licensed, ~2 GB
├── output/                          ignored: full run output (Phase 6)
├── loinc_cui_simple_lookup_<release>.json   ignored: UMLS CUI cache (Phase 5)
└── .venv/                           ignored: uv virtual environment
```

## Tracked files

| Path | Purpose | Maintained by |
|---|---|---|
| `README.md` | Operator quick-start for each release | Hand |
| `docs/` | Model and process reference (this folder) | Hand |
| `loinc_to_ocl_transformer.ipynb` | The ETL. See [01](01-pipeline-overview.md). | Hand |
| `File Splitter.ipynb` | Three independent cells for splitting outputs: `concepts.json` by size (30 MB, with optional text substitution); `mappings.json` by line count (50,000); `hierarchy_only.json` by size (5 MB) or by number of parent keys. Paths are hard-coded to the 2.81 production output folder, so edit them before use. Needs the `ndjson` package, which is imported but not used and is not in `pyproject.toml`. Remove the import or install it. | Hand |
| `id-check.ipynb` | Reads a full OCL source export (`export.json`, written for the 2.71 export) and writes CSVs of concept ids with `retired`, and mapping ids with `from`/`to`/`map_type`. Useful for comparing an older OCL LOINC load against new output. Paths are hard-coded. | Hand |
| `pyproject.toml`, `uv.lock`, `.python-version` | Environment definition. Runtime: `pandas`, `numpy`, `requests`, `pip`. Dev group: `jupyter`, `nbconvert`, `ipykernel`. | Hand |
| `.gitignore` | Ignores CSVs, `output/`, `LOINC_*`, zips, venvs, logs, and more. | Hand |
| `QA-Load-files/qa_concepts.json`, `qa_mappings.json`, `qa_hierarchy_only.json` | Small consistent subset for smoke-testing an import. Regenerated by Phase 7 each run and committed. Do not hand-edit. | Notebook |
| `Source-Import-files/LOINC-Source-Import LOINC_updated30Sep2025.json` | **Current** Source definition: a Source JSON object with properties, filters, locales and display meta. See [02](02-input-model.md#hand-maintained-input-the-ocl-source-definition). | Hand |
| `Source-Import-files/LOINC-Source-Import LOINC_updated22Sep2025.json` | Previous version, from the September 2025 production load prep. Differs from 30 Sep only in filter description wording ("Filter by ..." prefixes) and the order of `meta.display.concept_filter_order` and `concept_summary_properties`. | Hand |
| `Source-Import-files/LOINC-Source-Import LOINC-2-81_updated18Sep2025.json` | Version for a staging Source named `LOINC-2-81` with `en-GB` locale. | Hand |
| `Source-Import-files/Source-PUTs-LOINC-22Sep2025` | The 22 Sep definition split into separate JSON bodies (locales, descriptive fields, properties, and so on) for PUT updates to an existing Source. | Hand |
| `Source-Import-files/Archive/` | Earlier definitions, all still using the `en-GB` locale. They cover Sources `LOINC`, `LOINC-2-81` (staging) and `LOINC-small` (test). Kept for history. | Hand |

## Ignored, local-only files

| Path | Created by | Notes |
|---|---|---|
| `Input/*.csv`, `Input/LinguisticVariants/` | Phase 0 | Overwritten on every run from `source_loinc_directory`. Safe to delete. |
| `Input/MRCONSO.RRF` | You (UMLS download) | UMLS-licensed. Needed only to rebuild the CUI cache. The repo root `.gitignore` ignores `*.RRF`. |
| `loinc_cui_simple_lookup_<release>.json` | Phase 5 | `{LOINC code: CUI}`, ~6.5 MB. Ignored via `LOINC_*` on case-insensitive git only (see [07](07-data-quality-and-known-issues.md) P3). |
| `loinc_cui_api_cache_<date>.csv` | Phase 5, only if a UMLS API key is configured | Not produced in normal runs. |
| `UMLS_API_config.json` | You, optional | Would hold a UMLS API key. Ignored at the repo root. Not needed. |
| `output/` | Phase 6 | ~800 MB. Share it by drive, not git. |
| `executed_<release>.ipynb` | Headless run | Delete after review. |
| `.venv/` | `uv sync` | |

The repo root `.gitignore` also lists several old output folders from 2025 loads
(`output-arc`, `output-Staging-Load-30Aug25`, `output_full_02Sep2025`, and others). If
any of these still exist locally they are historical and not used by the notebook.
